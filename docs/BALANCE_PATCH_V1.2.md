# 平衡补丁 v1.2 实验报告（《灰港夜谭》）

> 引擎 v2.2 / AI v2（只读复用，未修改）；实验台 `scripts/balance-experiment.mjs`、
> 诊断 `scripts/balance-diagnose.mjs`、消融 `scripts/balance-ablation.mjs`、
> 候选矩阵 `scripts/balance-candidates.mjs`、定稿复核 `scripts/balance-final-check.mjs`。
> 所有随机走注入式 rng，无 `Math.random`，无外部依赖，无 DOM。
> 实验期通过临时 `options.cardOverrides` / `options.ruleOverrides` 注入数值；
> 定稿后已删除这两处临时钩子，最终数值只存在于
> `src/data/card-table.normalized.json` 与引擎常量中（单一事实源）。

## 1. 结论摘要

v1.1 已确认先手身份接近平衡（约 53–55%）。本轮复测确认：真正的 84% 来自
**教团预设牌组对学会预设牌组的强度差**，不是座位或先手。

消融实验把差距的绝大部分定位到**教团「献祭回响」阵营被动**（+2，祭坛 +3）：
单独把该被动置 0，P1（教团）胜率从 85.0% 降到 48.1%，**单次贡献 −36.9 个百分点**。
其余可疑卡（海祭司、千瞳、钟爪怪、深潜者、沉睡之主、降灵会、狂信徒等）
单卡贡献均在 ±2～8 个百分点以内；学会侧驱魔咒/结界术触发后胜率接近或低于
阵营基线，并非「过强」，但也几乎不贡献胜率。

定稿规则：**被动 +2/+3 → +1/+1**，并对 7 张教团侧高战力/滚雪球卡做数值下修。
未改动预设份数与组成，未增强学会（手段 ①② 已足够）。
同种子 2000 局、使用引擎 shipped defaults 的定稿复核：

| 组 | 教团胜率 | 学会胜率 | 理智结束 | 先手胜率 | 守恒 |
|---|---:|---:|---:|---:|---|
| P0 学会 / P1 教团 | **48.85%** | 51.15% | 34.10% | 53.65% | ok |
| P0 教团 / P1 学会 | **48.45%** | 51.55% | 34.85% | 55.15% | ok |
| 教团镜像（1200 局） | 46.00% / 50.75%（平局 3.25%） | — | 81.42% | 55.42% | ok |
| 学会镜像（1200 局） | 48.17% / 51.58% | — | 0.00% | 50.17% | ok |

两个方向均落入 45–55%，镜像保持 50% 附近，理智结束占比 ≥10%，92 项既有测试全绿。

## 2. 第一阶段·诊断（先出数据再动手）

命令：
```
node scripts/balance-diagnose.mjs --games=1000 --seed=balance-v1.2 --out=docs/v12-diagnose.json
```

### 2.1 镜像对局（各 400 局，确认无座位问题）

| 组 | P0 胜 | P1 胜 | P0/P1 胜率 | 先手胜率 | 理智结束 | 平均夜分 (P0/P1) |
|---|---:|---:|---:|---:|---:|---:|
| 教团 vs 教团 | 179 | 207 | 44.8% / 51.7% | 56.0% | 79.5% | 43.77 / 43.83 |
| 学会 vs 学会 | 191 | 209 | 47.8% / 52.3% | 48.8% | 0.0% | 58.65 / 58.86 |

教团镜像的 P0/P1 起伏（±3%）落在 400 局抽样噪声内，且**平均夜分几乎相等**
（43.77 vs 43.83），座位本身不产生分数偏差。先手约 48.8–56%，与 v1.1 的
「先手接近平衡」一致。教团镜像理智结束占比高（79.5%）源自双方都带
沉睡之主/献祭反噬，属于牌组自伤特性，不是座位效应。

### 2.2 交叉基线（同种子 1000 局，按座位/先手分组）

| 组 | P0（学会）胜 | P1（教团）胜 | 先手胜率 | 先手=P0 占比 | 理智结束 | 平均夜分 |
|---|---:|---:|---:|---:|---:|---:|
| 学会 vs 教团 | 148 (14.8%) | 852 (85.2%) | 54.7% | 47.9% | 12.9% | 46.40 / 67.78 |

教团平均每局夜分高出约 21.4，确认强度差来自牌组而非身份。
2000 局复核基线（同种子 `balance-v1.2-final`，实验台口径）
P1 教团 84.5% / 83.8%（两个座位方向），与 84% 一致。

### 2.3 逐卡贡献（1000 局，教团 P1 / 学会 P0 分列）

统计口径：每张卡的打出频率、入场时有效战力（`currentUnitPower` 在入场效果
结算完成后取样）、被抽到/被打出与胜负的关系。完整数据见
`docs/v12-diagnose.json`。要点：

- 教团高频高价值：钟爪怪 73.7% 打出率、入场有效战力 **9.1**；千瞳 10.3；
  沉睡之主 9.4；深潜者 6.9；海祭司 74.5% 打出率。
- 疯狂面很少出现：深潜者仅 4%、千瞳 9%、钟爪怪 11% 的入场为疯狂面
  （起始理智 6，理性面门禁 §9.7）。因此「疯狂面 +3」本身不是 84% 的主因，
  但高基础战力与献祭滚雪球叠加后影响显著。
- 学会低效卡：暴雨夜打出后胜率 5.2%（低于阵营基线 14.8%，且 -2 也打到自己
  的现场卡）；驱魔咒 11.2%、结界术 10.0%、旧图书馆 9.8%、银灯 11.0%、露西娅 10.3%。
  这些卡不是「过强」，而是触发收益低。学会真正强卡是千瞳（打出后胜率 19.8%、
  入场战力 7.1）与弗兰克（15.9%）。

## 3. 消融实验（同种子 1000 局）

命令：
```
node scripts/balance-ablation.mjs --games=1000 --seed=balance-v1.2 --out=docs/v12-ablation.json
```
方法：把目标卡替换为**同类型/同地点/同理智成本、关键词与效果清空、单位战力
降到 2** 的空白卡（通过临时 `cardOverrides` 注入，不改 JSON），同种子重打。
`deltaP1pp = 消融后教团胜率 − 基线教团胜率`。基线 P1 = **85.0%**。
完整结果见 `docs/v12-ablation.json`，按贡献排序：

| 消融项 | P1 胜率 | Δpp | 解释 |
|---|---:|---:|---|
| 教团被动置 0（+2/+3 → 0/0） | 48.1% | **−36.9** | 绝对主因：献祭后全场 +2 几乎常驻 |
| 学会千瞳 → 空白 | 94.5% | +9.5 | 学会最强单卡（封领袖 + 隐秘计数） |
| 教团沉睡之主 → 空白 | 92.4% | +7.4 | 自伤卡：抽到时教团反而更容易输 |
| 教团降灵会 → 空白 | 90.2% | +5.2 | 献祭换 2 张回收，净收益为负 |
| 学会弗兰克 → 空白 | 89.6% | +4.6 | 学会第二强卡 |
| 教团海祭司 → 空白 | 80.7% | −4.3 | 腐化滚雪球的有效载体 |
| 教团千瞳 → 空白 | 80.9% | −4.1 | 教团侧千瞳同样强 |
| 教团钟爪怪 → 空白 | 81.6% | −3.4 | 入场平均 9.1 战力 |
| 学会芬恩 → 空白 | 87.6% | +2.6 | 中性卡，双方共享 |
| 教团芬恩 → 空白 | 82.7% | −2.3 | 中性卡，双方共享 |
| 学会伊迪丝 → 空白 | 87.7% | +2.7 | 档案连锁 |
| 教团深潜者 → 空白 | 83.5% | −1.5 | 高基础战力 |
| 祭坛加成 +3 → +2 | 84.3% | −0.7 | 单独改祭坛几乎无效（被动基数才是主因） |
| 教团蒙面信徒 → 空白 | 84.2% | −0.8 | 献祭替身/吞噬目标 |
| 学会驱魔咒 → 空白 | 85.4% | +0.4 | 低效，但不足以解释差距 |
| 学会结界术 → 空白 | 85.3% | +0.3 | 触发率低 |

结论：优先手段 ①（被动量 + 超标卡数值）足够，无需 ② 份数调整或 ③ 学会增强。

## 4. 第二阶段·候选矩阵与定稿

命令示例：
```
node scripts/balance-candidates.mjs --games=2000 --seed=balance-v1.2-final \
  --only=baseline,passive=1/1+packageB+extra --out=docs/v12-candidates-final.json
```
每组同种子跑四个方向（crossAB / crossBA / 教团镜像 / 学会镜像）。
筛选过程（600–1000 局）要点：

| 方案 | crossAB 教团 | crossBA 教团 | 备注 |
|---|---:|---:|---|
| 基线 | 83.3% | 84.0% | — |
| 被动 1/3 | 77.0% | 76.5% | 单独降被动不足 |
| 被动 1/1 | 72.8% | 69.5% | 仍超 band |
| 被动 0/0 | 51.5% | 49.0% | 数值达标，但等于删除被动（§7.2 规则冻结，不采用） |
| 仅卡面数值包（combo） | 80.8% | 75.8% | 单靠卡面数值最多 ~7pp |
| 被动 1/1 + 卡面组合 | 54.5% | 56.8% | 接近但 BA 越界 |
| **被动 1/1 + packageB+extra** | **52.8%** | **48.1%** | 入选（1000 局 finalA）；finalB 51.3%/49.5% |

稳健性：两个独立 1000 局种子集（finalA / finalB）分别为
52.8%/48.1% 与 51.3%/49.5%，最终 2000 局 shipped-defaults 复核为
48.85%/48.45%（见 §1）。三个样本集均在 45–55%。

## 5. 定稿改动清单（逐处理由）

### 5.1 阵营被动（引擎常量）

| 位置 | 旧 | 新 | 依据 |
|---|---:|---:|---|
| `src/engine/v2/scoring.js` `thisNightBonus` | +2 / 祭坛 +3 | **+1 / 祭坛 +1** | 消融 −36.9pp（§3），是唯一能把 85% 拉回 band 的杠杆；保留「每夜首次献祭后加成」机制，不删除被动 |

## 8. 剩余疑问（只记录，不自创规则）

1. **冻结规则文本与新数值不一致**：`docs/GREYHARBOR_RULES_V1.md` §7.2 写 +2/+3、
   §11.2 写狂信徒 9 / 深潜者 11 / 沉睡之主 8/12、溺钟祭坛效果写「+2 变 +3」。
   本轮按任务约束未修改该冻结文档；`BALANCE_PATCH_V1.2.md` 为现行数值口径。
   是否升版规则文档待授权。
2. **selfplay / ai-match 的理智结束占比偏高**（45.5% / 40.5%）：这两个脚本使用
   自定义/混合牌组，非本补丁的定稿口径；本补丁只对官方预设的双向交叉负责
   （34.1% / 34.85%，均 ≥10%）。
3. **教团镜像先手胜率 55.42%**：略高于 v1.1 的 53–55% 区间上沿，但镜像 P0/P1
   差异在抽样噪声内（46.0% vs 50.75%，3.25% 平局）。未据此新增补偿规则。
4. **`npm test` 在本机（Windows / pwsh）报告 0 项**：`package.json` 的
   `"node --test 'tests/*.test.mjs'"` 引号阻止 glob 展开；直接运行同一命令得到
   106 项。该问题早于本补丁且 `package.json` 不在允许改动范围，故未修改。
5. **商品化取舍**：被动从 +2/+3 降到 +1/+1 后，溺钟祭坛的「升级被动」文本在
   数值上成为 no-op（其「现场献祭免反噬」仍有效）。是否改卡面文本待授权。
6. **实验脚本历史性**：`balance-diagnose.mjs` / `balance-ablation.mjs` /
   `balance-candidates.mjs` 是 v1.2 实验期脚手架，曾依赖已删除的
   `cardOverrides` / `ruleOverrides` 引擎钩子；其原始数据固化在
   `docs/v12-*.json`。定稿后重跑这些脚本只会使用 shipped JSON，不再复现
   历史消融/候选数值（用途见各脚本头注释）。
